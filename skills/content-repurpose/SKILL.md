# Content repurpose

One original project per week. The topic can repeat. The purpose cannot.

| Property | Job | Cadence |
| --- | --- | --- |
| Stack Snacks | Teach and grow an audience | Tuesday email. YouTube when the week has room |
| johnsiwicki.com | Prove John can do valuable work | One or two case studies a month |
| @siwicadilly | Start a conversation | Three useful posts weekly plus replies |

## Do not use when

- There is no original project yet. Make the thing first.
- The user wants a second content machine. That is a `chief-of-staff` Kill.
- Friday video is crowding out Tuesday. Protect Tuesday.

## Inputs

- The project / video / issue
- What shipped (proof)
- Optional transcript or outline

## Sorting rule

- Helps someone do something → Stack Snacks
- Demonstrates how John thinks and builds → johnsiwicki.com
- Invites discussion → @siwicadilly

## Workflow

1. Write the **teach** version: tools, steps, what worked, what failed, how to try it this week.
2. Write the **prove** version only if this is case-study strong: problem, constraints, decisions, screenshots, what you would change. Skip it most weeks.
3. Write **three X posts** with different jobs:
   - The problem in plain numbers or steps
   - The lesson or screenshot from the build
   - A question that invites replies
4. Write **three Notes** that point at the Tuesday issue, not at a new landing page.
5. If a video exists, run `youtube-packaging` for title/thumb/hook. Spoken CTA in the first 20 seconds and at the end: one email a week at stack-snacks.com.

## Default weekly rhythm

- Tuesday: email ships. Same day: 3 X posts + 3 Notes pointing at the issue.
- YouTube: only if the week has room. Never skip Tuesday to make a video.
- Sunday (10 min): subscriber count and whether Tuesday shipped. Nothing else.

## Output

Labeled drafts:

1. Newsletter angle (or pointer to `stack-snacks-issue`)
2. Three X posts
3. Three Notes
4. Optional johnsiwicki.com outline
5. Pin line if needed: `One email a week on the tools I actually keep, skip, or try. stack-snacks.com`

## Guardrails

- Do not create a new brand, hub, or newsletter to distribute the same idea.
- Do not reuse the same metaphor in the title, thumbnail, and hook. That is `youtube-packaging`.
- If the week is crowded, ship the original project, the newsletter, and one X post. The rest can wait.
